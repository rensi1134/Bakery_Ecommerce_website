# 🍰 Bakery E-commerce Website

A static e-commerce website layout for a bakery, built using **HTML** and **CSS**. This project is a front-end-only implementation, designed to showcase a beautiful and responsive layout suitable for a bakery or similar small business.

## 🖼️ Features

- Responsive and modern layout
- Home page with hero section
- About Us and Contact pages
- CSS styling for a clean, aesthetic design
